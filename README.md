# 🏧 ATM Machine Simulator
A modern ATM Machine Simulator built with Java, featuring both **ATM Kiosk Mode** and **Java CLI Terminal Mode**. The application simulates real ATM operations such as balance inquiry, cash withdrawal, deposits, transaction history, and account management.

## 🚀 Live Demo

https://new-atm-machine.vercel.app/

---

## ✨ Features

- 🔐 Secure ATM Login
- 💰 Balance Inquiry
- 💵 Cash Deposit
- 💸 Cash Withdrawal
- 📄 Mini Statement / Transaction History
- 🏦 View Account Details
- 👤 Personal & Account Information
- 🏧 ATM Kiosk Mode
- 💻 Java CLI Terminal Mode
- 📱 Responsive Interface
